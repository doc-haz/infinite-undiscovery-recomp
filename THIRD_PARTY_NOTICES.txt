F. LGPL (FFmpeg, libmspack) - corresponding source and relink materials
----------------------------------------------------------------------------
rexruntime.dll statically links libmspack (LGPL-2.1) and FFmpeg's libavcodec /
libavutil (LGPL-2.1-or-later; built with CONFIG_GPL=0, i.e. no GPL parts).

Under LGPL-2.1 section 6, distributing a work linked with the Library requires,
besides this notice and the license texts, either the corresponding Library
source plus the relinkable "work that uses the Library", a shared-library
mechanism, or equivalent materials. That material is published alongside this
release in a separate package:

    InfiniteUndiscoveryRecomp-v1.0.0-rc1-LGPL-Compliance.zip

It contains the exact FFmpeg source (submodule commit
0604b464c7cb4ebc94940cf1f324a3b26b87717c) and libmspack source (submodule commit
305907723a4e7ab2018e58040059ffb5e77db837), their upstream LGPL license texts,
the ReXGlue objects and non-LGPL static libraries used to produce
rexruntime.dll, the export definition, the exact link command, and scripts that
rebuild the LGPL libraries and relink rexruntime.dll.

The relink procedure was executed and verified for this release: rebuilding
libmspack (with a local modification) and rebuilding FFmpeg's libavutil from the
provided sources, then relinking, both produced a rexruntime.dll with the
identical 10,169-symbol export set, and the relinked DLL was confirmed to run
the game.

This notice states facts taken from the upstream sources; it is not a legal
opinion.
